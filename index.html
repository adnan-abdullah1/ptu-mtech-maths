    Discrete Random Variables
    & Probability Distributions

    From a coin flip to the mathematics behind uncertainty.

    The idea

    What even is a random variable?

    First, what's a variable? Something that changes - marks in an exam, height of a person, number of children in a family. It takes different values in some range.

    Now, what makes a variable random? When there's a chance factor attached to which value it takes. The life of a person is a variable, but which value it takes depends on probability - that makes it a random variable.

    Where do these random variables come from? From random experiments - things whose outcome you can't predict beforehand.

    Tossing a coin
    Rolling a dice
    Counting defects in a batch
    Picking a student at random

    We define a variable = "the number that appears." Now can be 1, 2, 3, 4, 5, or 6.

    That's a random variable -a rule that turns experiment outcomes into numbers.

    • It's a variable because it takes different values.
    • It's random because which value depends on an unpredictable experiment.
    Key insight A random variable is not the dice. It's not the coin. It's the mathematical rule that assigns a number to each outcome.
    Also known as A random variable is also called a stochastic variable or a chance variable. Different names, same thing. If you see any of these on the exam, they all mean random variable.
    A distinction

    What makes it discrete?

    Not all random variables are the same. A discrete random variable takes countable values -you can list them out. Compare:

    ExperimentPossible valuesType
    Rolling a dice1, 2, 3, 4, 5, 6Discrete
    Tossing 3 coins (# heads)0, 1, 2, 3Discrete
    Server requests per hour0, 1, 2, 3, …Discrete
    Height of a person165.1, 165.11, …Continuous
    Time to finish a taskAny real number ≥ 0Continuous
    Watch out "Countable" doesn't mean finite. Server requests can be 0, 1, 2, 3, … forever -still discrete. Continuous means the values fill an entire interval with no gaps.

    Exam-ready definition

    A discrete random variable is a function that assigns a real number to each outcome of a random experiment, and its range consists of a finite or countably infinite set of distinct values.

    So now we know what is, what "discrete" means, and how to map outcomes to numbers. But that's only half the picture.

    Exam-ready definition

    A discrete probability distribution describes the probabilities associated with all possible values of a discrete random variable. It specifies the probability of each possible value that the random variable can assume.

    Putting it together

    The complete chain

    Every problem in this unit follows the same sequence:

    Random experiment → Sample space → Random variable → Possible values → Probability distribution → PMF

    First, we perform a random experiment -something with an unpredictable outcome. Then we list every possible outcome in the sample space. Next, we define a random variable -a rule that maps each outcome to a number. Once we know all possible numerical values, we calculate the probability of each one to get the probability distribution. Finally, we express those probabilities as a function -the PMF -and verify it satisfies both conditions (non-negative, sums to 1).

    Foundation This chain is the foundation for everything ahead -expected value, variance, and the standard distributions (Binomial, Poisson). If any step in the chain is unclear, the rest won't make sense.
