    Discrete Random Variables
    & Probability Distributions

    From a coin flip to the mathematics behind uncertainty.

    The idea

    What even is a random variable?

    First, what's a variable? Something that changes - marks in an exam, height of a person, number of children in a family. It takes different values in some range.

    Now, what makes a variable random? When there's a chance factor attached to which value it takes. The life of a person is a variable, but which value it takes depends on probability - that makes it a random variable.

    Where do these random variables come from? From random experiments - things whose outcome you can't predict beforehand.

The book also calls it a stochastic variable or chance variable; all three names mean the same thing.

    Key insight A random variable is not the dice. It's not the coin. It's the mathematical rule that assigns a number to each outcome.
    Exam-ready definition

    A random variable is a real variable whose value is determined by the outcome of a random experiment. Equivalently, it is a real-valued function defined on the sample space of the experiment.

    A distinction

    What makes it discrete?

    A random variable is discrete if it takes only separate, listable values, like . These are the standard examples:

    Finite or countably infinite Your book says a discrete variable takes a finite number of values. But printing mistakes and phone calls have no fixed upper limit, so they go 0, 1, 2, … forever. That's still discrete, because you can list the values. The complete definition is finite or countably infinite. If your exam follows the book, write "finite"; just know the full version includes the infinite case. Continuous is different: the values fill an entire interval with no gaps.

    Putting it together

    The complete chain

    Every problem in this unit follows the same sequence:

    Random experiment → Sample space → Random variable → Possible values → Probability distribution → PMF

    First, we perform a random experiment -something with an unpredictable outcome. Then we list every possible outcome in the sample space. Next, we define a random variable -a rule that maps each outcome to a number. Once we know all possible numerical values, we calculate the probability of each one to get the probability distribution. Finally, we express those probabilities as a function -the PMF -and verify it satisfies both conditions (non-negative, sums to 1).

    Foundation This chain is the foundation for everything ahead -expected value, variance, and the standard distributions (Binomial, Poisson). If any step in the chain is unclear, the rest won't make sense.
